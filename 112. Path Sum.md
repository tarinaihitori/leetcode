1st
再帰的にノードを探索し、葉に到達した時点でtargetSumと現在のノードの値が等しいかを確認する
時間計算量：O(n)
空間計算量：O(n) バランしている場合はlog n

```python
class Solution:
    def hasPathSum(self, root: Optional[TreeNode], targetSum: int) -> bool:
        if root is None:
            return False

        if root.left is None and root.right is None:
            return targetSum == root.val

        return (self.hasPathSum(root.left, targetSum - root.val) or
                self.hasPathSum(root.right, targetSum - root.val))
```

2nd
関数内関数を用いた再帰。
ノードを辿っていくごとにcurrent_sumが追加されるというのが直感的にわかりやすい。
また、1stの再帰に比べてtargetSumに一致するノードの経路がほしいとなった場合の拡張性が高いところが嬉しい。
再帰なのでスタックオーバーフローには注意する。

```python
class Solution:
    def hasPathSum(self, root: Optional[TreeNode], targetSum: int) -> bool:
        def check_path_sum(node: Optional[TreeNode], current_sum :int) -> bool:
            if node is None:
                return False
            
            current_sum += node.val

            if node.left is None and node.right is None:
                return current_sum == targetSum
            
            return check_path_sum(node.left, current_sum) or check_path_sum(node.right, current_sum)
        return check_path_sum(root, 0)
```

stack を用いた DFS。
スタックオーバフローは考慮しなくて良いが、コードが少し複雑になっている。

```python
class Solution:
    def hasPathSum(self, root: Optional[TreeNode], targetSum: int) -> bool:
        if root is None:
            return False
        node_and_sum = [(root, targetSum)]

        while node_and_sum:
            node, current_sum = node_and_sum.pop()

            if node.left is None and node.right is None and current_sum == node.val:
                return True

            if node.right:
                node_and_sum.append((node.right, current_sum - node.val))
            if node.left:
                node_and_sum.append((node.left, current_sum - node.val))

        return False

```

BFS
葉ノードかどうか判定を変数に代入した。

```python
class Solution:
    def hasPathSum(self, root: Optional[TreeNode], targetSum: int) -> bool:
        if root is None:
            return False

        queue = deque([(root, targetSum)])
        while queue:
            node, current_sum = queue.popleft()
            is_leaf = node.left is None and node.right is None
            if is_leaf and current_sum == node.val:
                return True
            if node.left:
                queue.append((node.left, current_sum - node.val))
            if node.right:
                queue.append((node.right, current_sum - node.val))
        return False
```
