上以外は思いつかなかったので答えを見た。
累積和を作って、そこから計算したら行けるということで、書いてみた。
max_sum の初期値はnums[0]を選択。
-sys.maxsize -1を使う人もいたが、わざわざ定数を置く必要がないのと、Python の int 型は任意精度なので、sys.maxsize を超える値が来る可能性もあるため。

```python
    def maxSubArray(self, nums: List[int]) -> int:
        if not nums:
            return 0

        nums_length = len(nums)
        prefix_sum = [0] * (nums_length + 1)

        for i in range(nums_length):
            prefix_sum[i + 1] = prefix_sum[i] + nums[i]
        
        max_sum = nums[0]
        for i in range(1, nums_length + 1):
            for j in range(i):
                max_sum = max(max_sum, prefix_sum[i] - prefix_sum[j])
        
        return max_sum
```

累積和を使ったコードと分割統治法で解く方法もある。
left_suffix_max：中央から左へスライドしながら部分和を取り、その最大値を取る
right_prefix_max：中央＋１から右へスライドしながら部分和を取り、その最大値を取る
cross_max：両者の合算が、中央をまたぐ「最良の」部分配列和になる

```python
class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        if not nums:
            return 0

        def max_sub_array_helper(left: int, right: int) -> int:
            if left == right:
                return nums[left]

            mid = (left + right) // 2
            left_max = max_sub_array_helper(left, mid)
            right_max = max_sub_array_helper(mid + 1, right)

            temp = 0
            left_suffix_max = float('-inf')
            for i in range(mid, left - 1, -1):
                temp += nums[i]
                left_suffix_max = max(left_suffix_max, temp)

            temp = 0
            right_prefix_max = float('-inf')
            for i in range(mid + 1, right + 1):
                temp += nums[i]
                right_prefix_max = max(right_prefix_max, temp)

            cross_max = left_suffix_max + right_prefix_max

            return max(left_max, right_max, cross_max)

        return max_sub_array_helper(0, len(nums) - 1)

```

class Solution:
    def maxSubArray(self, nums: List[int]) -> int:
        current_sum = nums[0]
        max_sum = nums[0]

        for i in range(1, len(nums)):
            current_sum = max(current_sum + nums[i], nums[i])
            max_sum = max(max_sum, current_sum)
